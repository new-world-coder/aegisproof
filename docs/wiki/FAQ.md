# FAQ

**Is a green verify “EU AI Act compliant”?**  
No. Integrity only.

**Is this an AI SBOM?**  
No. Use SPDX / CycloneDX for inventory. AegisProof packages *evidence artefacts*.

**Do I need an LLM?**  
No.

**Can I use YAML?**  
Yes. JSON Schema is the validation source of truth; YAML is authoring sugar.

**Relation to RiskLine?**  
Sister project / potential consumer. AegisProof stays vendor-neutral.
