# Governance (early)

AegisProof is in early development under a benevolent-maintainer model.

## Spec changes

- Propose via GitHub issue labelled `spec`
- Breaking changes bump `specVersion` and update `schema/` + `conformance/`

## Neutrality

RiskLine, XERJ, and other tools may consume or emit AegisProof packages but do not own this specification.

## Later

When ≥2 independent emitters exist, introduce a lightweight technical steering process. Foundation transfer is not planned until neutrality becomes an adoption requirement.
